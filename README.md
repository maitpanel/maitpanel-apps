# Maitpanel apps · মেইটপ্যানেল অ্যাপ

Android and iPhone apps for every Maitpanel website. Each app opens the live website full screen, like a normal app,
so **every update reaches you by itself**: when we update the website, the app shows the new version the next time you
open it. You never have to download it again, and the links below never change.

মেইটপ্যানেলের প্রতিটি ওয়েবসাইটের Android ও iPhone অ্যাপ। অ্যাপ খুললে লাইভ সাইটটা পুরো স্ক্রিনে অ্যাপের মতো চলে, তাই
**আপডেট নিজে থেকেই আসে**: আমরা সাইট আপডেট করলে পরের বার অ্যাপ খুললেই নতুনটা দেখবেন। আবার ডাউনলোড করতে হবে না,
নিচের লিংকও কখনো বদলাবে না।

**Install · ইনস্টল**
1. Tap the download link on the phone. · ফোনে ডাউনলোড লিংকে চাপ দিন।
2. Open the downloaded file. Android may ask to allow "Install unknown apps" for Chrome (or Files): allow it once.
   · ডাউনলোড হওয়া ফাইলটা খুলুন। Android "Install unknown apps" অনুমতি চাইলে Chrome (বা Files)-কে একবার অনুমতি দিন।
3. Tap **Install**. If Play Protect says "unknown developer", tap **More details → Install anyway**.
   · **Install** চাপুন। Play Protect "unknown developer" বললে **More details → Install anyway**।
4. Keep Chrome installed and up to date (the app uses it to show the site). · Chrome ইনস্টল ও আপডেট রাখুন।

Every app is signed with the same Maitpanel key, so a newer APK installs over the old one without losing anything.
· সব অ্যাপ একই মেইটপ্যানেল কী দিয়ে সাইন করা, তাই নতুন APK পুরোনোটার ওপর বসে যায়, কিছু হারায় না।

## iPhone / iPad (no download needed · ডাউনলোড লাগবে না)

On iPhone the website itself installs as an app (Apple does not allow apps from outside the App Store; this way it is
free, opens full screen with its own icon, and updates by itself):
1. Open the website in **Safari** (links in the table above).
2. Tap **Share** (the square with the arrow) → **Add to Home Screen** → **Add**.
3. Open it from the new icon on the home screen.

iPhone-এ ওয়েবসাইটটাই অ্যাপ হিসেবে বসে (অ্যাপ স্টোরের বাইরে থেকে অ্যাপ বসাতে Apple দেয় না; এভাবে বিনামূল্যে, নিজের
আইকনসহ পুরো স্ক্রিনে খোলে আর নিজে থেকেই আপডেট হয়):
1. **Safari**-তে সাইটটা খুলুন (ওপরের টেবিলের লিংক)।
2. **Share** (তীরসহ চৌকো) → **Add to Home Screen** → **Add**।
3. হোম স্ক্রিনের নতুন আইকন থেকে খুলুন।
